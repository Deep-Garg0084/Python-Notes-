NOTE:-
enumerate() is a built-in Python function that allows us to get both the index (position) and the value (element) together while using a loop

Example:-
fruits = ["Apple", "Banana", "Mango"]
for fruit in fruits:
    print(fruit)

Apple 
Banana
Mango 

Example:-
fruits = ["Apple", "Banana", "Mango"]
for i, fruit in enumerate(fruits):
    print(i, fruit)

0 Apple
1 Banana
2 Mango

NOTE:-
By default, enumerate() starts counting from 0
But we can change it using start

Example:-
fruits = ["Apple", "Banana", "Mango"]
for i, fruit in enumerate(fruits, start = 1):
    print(i, fruit)

1 Apple
2 Banana
3 Mango

--> Project - AI Auto Directory Creator 

import os
folders = ["data", "models", "scripts", "notebook", "output"]
project = input("Enter AI project name: ")

for folder in folders:
    path = os.path.join(project, folder)
    os.makedirs(path, exist_ok = True)
    print(f"Created: {path}")
print("AI project directory created successfully!")

NOTE:-
It creates a main project directory and automatically creates five subdirectories inside it

The os module helps Python interact with the operating system, such as creating folders and managing file paths
os.path.join()  - combines folder names into a proper path
os.makedirs()   - creates the directory, including parent directories if needed
exist_ok = True - prevents an error if the directory already exists
