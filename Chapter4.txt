Dictionary are used to store data values in key:value pairs
They are unordered, mutable (changeable) and don't allow duplicate keys

setdefault()  Returns the value of the specified key. If the key does not exist: insert the key, with the specified value

values()	  Returns a list of all the values in the dictionary

Merging Dictionaries:-

Example:-
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

merged = {**d1, **d2}
print(merged)

{'a': 1, 'b': 3, 'c': 4}

NOTE:-
**d1 -         Unpacks all key-value pairs from the first dictionary.
**d2 -         Unpacks all key-value pairs from the second dictionary.
{**d1, **d2} - Combines both dictionaries into a new dictionary.

* -  Unpacks iterables like lists and tuples.
** - Unpacks dictionary key-value pairs.

Example:-
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}
merged = d1 | d2
print(merged)

{'a': 1, 'b': 3, 'c': 4}

NOTE:-
| -> Merges dictionaries (Python 3.9+)

Set:-
Set is the collection of the unordered items 
Each element in the set must be unique and immutable 

Set are an unordered collection of unique and immutable elements
They are useful when you need to store distinct values and perform set operations like union, intersection, and difference 

In set, indexing is not allowed because set is unordered

Allowed - Immutable types like integers, strings, and tuples
Not allowed - Mutable types like lists or dictionaries

set = mutable
values = immutable

A frozenset is a collection of unique elements that cannot be changed after creation.

set - Mutable (can be changed).
frozenset - Immutable (cannot be changed).

Q. Create a program that counts the number of unique words in a paragraph 

def unique_word_count(text):
    word = text.lower().split()
    unique_w = set(word)
    return len(unique_w)

paragraph = "Python is great and great easy easy to use"
print(unique_word_count(paragraph))
