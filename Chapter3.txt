Built-In List Methods:-
These methods are called using dot notation

append():  Adds an element to the absolute end of the list.
extend():  Appends all individual elements of an iterable to the list.
insert():  Inserts an item at a specific index location.
remove():  Deletes the very first occurrence of a specific value.
pop():     Removes and returns the item at a given index (defaults to the last item).
clear():   Strips out all elements, leaving the list completely empty.
index():   Returns the index position of the first occurrence of a value.
count():   Returns the total number of times a value appears.
sort():    Sorts the items of the list in place.
reverse(): Inverts the order of the elements inside the list in place.
copy():    Generates a shallow copy of the existing list.

Built-In Global Functions:-
These are built-in global tools in Python where you pass the list as a parameter (e.g., len(my_list))

len():       Counts and returns the total number of elements.
max():       Finds the largest item within the list.
min():       Finds the smallest item within the list.
sum():       Calculates the total sum of numeric items.
sorted():    Returns a brand new sorted list without modifying the original.
list():      Converts another iterable data type into a list object.
any():       Returns True if at least one item evaluates to true.
all():       Returns True only if every single item evaluates to true.
enumerate(): Pairs list items with their index numbers for looping.
zip():       Aggregates elements from multiple lists into corresponding tuples.

Python has a set of built-in methods that you can use on lists/arrays.

Note: Python does not have built-in support for Arrays, but Python Lists can be used instead.

Q. Find the highest percentage


# Q. Find the Highest Percentage

def topper(students):
    highest_avg = 0
    topper_name = ""

    for name, marks in students:
        avg = sum(marks) / len(marks)

        if avg > highest_avg:
            highest_avg = avg
            topper_name = name

    return topper_name, highest_avg


students = [
    ("Riya", [50, 60, 10]),
    ("Priya", [70, 80, 80]),
    ("Amit", [90, 80, 80])
]

name, percentage = topper(students)

print(f"Topper: {name}")
print(f"Highest Percentage: {percentage:.2f}%")

Topper: Amit
Highest Percentage: 83.33%
