Class and Object:-
Class is a blurprint for creating objects. Objects are instance of class 
A class is a blueprint or template used to create objects. It defines the structure (data + functions)

Object    - An object is an instance of a class. It has actual values and can use the functions defined in the class 
Attribute - Attributes are the variables or data inside an object (like name, age, color)
Method    - Methods are the functions defined inside a class that perform actions on object data

class - car
object - C1, C2, C3
Attributes/properties - color, model
methods/features/actions - move, open door, close door

Static methods:-
A static method is a method inside a class that does not use self 
It works like a normal function but is placed inside a class for better organization 

Methods that don't use the self parameter (work at class level)

In Python, a static method is a method that belongs to a class but does not need an object or access to the class itself.
We create a static method using the @staticmethod decorator.

Decorators allow us to wrap another function in order to extend the behaviour of the wrapped function, without permanently modifying it 

Example:-
class Student:
    @staticmethod            #decorator 
    def college():
        print("ABC college")

Student.college()

ABC college

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks
        
    def __str__(self):
        return f"Student data: {self.name}, marks: {self.marks}"
    
    def __len__(self):
        return len(self.marks)
    
    def __eq__(self, other):
        return sum(self.marks) == sum(other.marks)
    
    def __add__(self, other):
        return sum(self.marks) + sum(other.marks)
    
    def __gt__(self, other):
            return sum(self.marks) > sum(other.marks)
        
    def __lt__(self, other):
            return sum(self.marks) < sum(other.marks)
        
    def __contains__(self, other):
        return other in self.marks
    
s1 = Student("Arpit", [10, 25, 30])
s2 = Student("Anjali", [10, 90, 30])

print(s1)
print(len(s1))
print(len(s2))
print(s1 == s2)
print(s1 + s2)
print(s1 > s2)
print(s1 < s2)
print(30 in s2)

Q. Define a cirlcle class to create a circle with radius r using the construction 
   Define an Area() method of the class which calculates the area of the circle     
   Define a perimeter() method of the class which allows you to calculate the perimeter of the circle 

class Circle:
    def __init__(self, radius):
        self.radius = radius 

    def area(self):
        return (22/7) * self.radius ** 2

    def perimeter(self):
        return 2 * (22/7) * self.radius

c1 = Circle(21)
print(c1.area())
print(c1.perimeter())

1386.0
132.0

Access Modifiers:-
Access Modeifiers in python are used to control the accessibility (visibility) of class attributes and methods 
public, protected, private 

Public members:-
Accessible from anywhere in your code - inside or outside the class 

Example:-
class Car:
    def __init__(self):
        self.brand = "Toyota"
        
car = Car()
print(car.brand)

Toyota

Protected members:-
Should only be accessed within the class or its subclasses. 
In python, it's just a convention using a single underscore(_)

Example:-
class Vehicle:
    def __init__(self):
        self._engine = "petrol"
        
class Bike(Vehicle):
    def show_engine(self):
        print("Engine type: ", self._engine)
        
b = Bike()
b.show_engine()

print(b._engine)

Engine type:  petrol
petrol

Important concept:-
In python, self._engine is protected by convention 
that means - we are saying "please don't access it from outside", but python won't stop you if you do

In Java/C++
Protected variable cannot be accessed outside the class or subclass 
print(b._engine)

Private members:-
Can only be accessed inside the class. Python uses double underscore(__)

Example:-
class BankAccount:
    def __init__(self):
        self.__balance = 10000
        
    def get_balance(self):
        return self.__balance
    
acc = BankAccount()
print(acc.get_balance())    #10000
print(acc.__balance)        #show error - AttributeError: 'BankAccount' object has no attribute '__balance'. Did you mean: 'get_balance'?

Encapsulation:-
Protecting data inside the class using private variables 

Example:-
class BankAccount:
    def __init__(self):
        self.__balance = 0   #private
        
    def deposit(self, amount):
        self.__balance = self.__balance + amount
        
    def get_balance(self):
        return self.__balance
    
acc = BankAccount()
acc.deposit(10000)
print(acc.get_balance())   #10000
print(acc.__balance)       #show error - AttributeError: 'BankAccount' object has no attribute '__balance'. Did you mean: 'get_balance'?
