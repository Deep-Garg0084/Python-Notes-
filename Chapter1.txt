Python character set:-
Letters - A to Z, a to z
Digits - 0 to 9
Special symbols - -,+,*,/ etc
Whitespaces - Black space, Tab, Carriage return, Newline, Formfeed

Other characters - Python can process all ASCII and unicode characters as part of data or literals 

Whitespaces are characters that represent empty space in text — they don’t show visible symbols but are used to separate words, format code, or control text layout.

Here are the main types of whitespace characters:

1. Blank Space (' ') – A normal space between words.
   Example: "Hello World" (space between Hello and World)

2. Tab (\t) – Moves the cursor to the next tab stop (used for indentation).
   Example: Hello\tWorld → Hello    World

3. Carriage Return (\r) – Moves the cursor to the beginning of the same line (used in old systems or with \n for new lines).
   Example: Hello\rWorld → World

4. Newline (\n) – Moves the cursor to the next line.
   Example: Hello\nWorld

            Hello
            World

5. Form Feed (\f) – Moves the cursor to the next page (used mainly in printers or page formatting).
   Example: It tells the printer to start a new page.

Identifier:-
An identifier is the name used to identify (or label) something in your program — like a variable, function, class, etc.

Example:-

name = "Deep"
age = 19
def greet():
    print("Hello!")
greet()

Hello!

Here:-
name and age → identifiers for variables
greet → identifier for a function

Rules for naming identifiers in Python:-        (ChatGPT)

1. An identifier can contain letters (A–Z, a–z).
2. It can contain numbers (0–9), but cannot start with a number.
3. Underscores (_) are allowed.
4. Spaces are not allowed.
5. Special characters like @, #, $, % are not allowed.
6. Python keywords like if, else, for, and class cannot be used as identifiers.
7. Identifiers are case-sensitive (name and Name are different).

Rules for naming identifiers in Python:-

1.They can contain letters (A–Z, a–z), digits (0–9), and underscores (_)
  Example: my_name, age2, _temp

2. They must not start with a digit
   2name → invalid
   name2 → valid

3. Case-sensitive
   Name and name are different identifiers.

4. No special symbols like @, $, %, #, -
   my-name → invalid

5. Keywords (like if, while, class, etc.) can’t be used as identifiers.
   if = 10 → invalid

6. Python allows Unicode characters in identifiers (not just ASCII).
   Example:
   नमस्ते = "Hello"
   print(नमस्ते)

   Output:
   Hello

Python is a typed language — but more specifically, it’s a dynamically typed language.

Typed language
It means every value in Python has a specific type (like int, float, str, etc.).
Even if you don’t mention the type, Python knows it internally.

Example:

a = 10        # int (integer)
b = 5.5       # float (decimal number)
c = "Deep"    # str (string)

Here, a, b, and c each have a type automatically.

Dynamic Typing
In Python, you don’t need to declare the variable type — it is decided at runtime based on the value assigned.

Example:

x = 10       # x is an int
x = "Hello"  # now x becomes a str

Python allows this — the type of x changes automatically.

Static Typing (for comparison)
In languages like C, C++, or Java, you must declare the type before using it.

Example (C++):

int x = 10;
x = "Hello";    //Error - can't assign string to int

Type Checking in Python:
a = 42
print(type(a))

Output:
<class 'int'>

Operators:-
Operators in python are special symbols or keyword used to perform operations on variables and values. 
Python supports several types of operators, including arithmetic, comparison, logical, assignment, and more 

Types of operator:-

1. Arithmetic operator              (+ - * / // % **)
2. Relational / Comparison operator (== != > < >= <=)
3. Assignment operator              (= -= += *= /= %= //= **=)     //Add and assign 
4. Logical operator                 (not, and, or)
5. Membership operator              (in, not in)
6. Identity operator                (is, is not)
7. Bitwise operator                 (&, |, ^)

Example of comparison and logical operator:-

age = 22
has_license = True 

if age >= 18 and has_license:
    print("You can drive")
else:
    print("Can't drive")

5. Membership operator:-
   Membership operators test for membership in a sequence (eg. strings, lists)

Example:- 

my_list = [1,2,3,4,5]

#Check if an item is in the list 
print(3 in my_list)   

#Check if an item is not in the list
print(6 not in my_list)

6. Identity operator:-
   Identity operators compare the memory locations of two objects

Example:-

x = [1,2,3]
y = [1,2,3]
z = x

#Check if two variables point to the same object 
print(x is z)     #True

#Check if two variable do not point to the same object 
print(x is not y)    #True

#Even though x and y have the same content, they are different objects 
print(x == y)     #True (same content)
print(x is y)     #False (different objects)

Type conversion:-
Type conversion in Python is the process of changing a value from one data type to another.

Python supports two types of type conversion:-

1. Implicit Conversion:-
   Python automatically converts one data type into another without requiring the programmer to do it manually.

Example:-
a = 10       # int
b = 2.5      # float
c = a + b

print(c)
print(type(c))

12.5
<class 'float'>

2. Explicit Conversion:-
   The programmer manually converts one data type into another using built-in functions.

Example:-
a = "100"
b = int(a)

print(b)
print(type(b))

100
<class 'int'>
