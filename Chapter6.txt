Variable length keyword arguments: **kwargs

Single star *args
*args collects multiple positional arguments into a tuple
You can pass any number of values

Double star **kwargs
**kwargs collects multiple keyword arguments into a dictionary
You pass values using key = value

**kwargs means accept any number of keyword arguments and collect them into a dictionary
**kwargs = multiple keyword = value pairs packed into a dictionary

Q. Binary search:-

def binary_se(arr, start, end, target):
    # Base condition - when start crosses end, stop recursion 
    if start > end:
        return -1
    
    # Find the middle index 
    mid = (start + end) // 2
    
    # Check if middle element is our target
    if arr[mid] == target:
        return mid
        
    # If target is smaller -> search left half 
    elif arr[mid] > target:
        return binary_se(arr, start, mid-1, target)
    
    # If target is greater -> search right half
    else:
        return binary_se(arr, mid+1, end, target)
    
# Driver code

target = 20
result = binary_se(arr, 0, len(arr) - 1, target)
