--> Lambda use

Example:-

words = ["python", "is", "awesome"]
capitalized = list(map(lambda word: word.capitalize(), words))
print(capitalized)

['Python', 'Is', 'Awesome']

NOTE:-
map() –             Applies a function to every element of an iterable.
lambda word: –      Creates a small anonymous function.
word.capitalize() – Makes the first character uppercase and the remaining characters lowercase.
list() –            Converts the map result into a list.

words = ["python", "is", "awesome"]

--> Project - animate string OR typewriter effect

sys = In this case, we use it to directly write output to the console (sys.stdout.write())
time = It allows us to pause the program using time.sleep() - this is what makes the typing effect possible

import sys 
import time 
text = "Welcome to python magic"

for char in text:
    sys.stdout.write(char)    #Prints one character without automatically adding a new line
    sys.stdout.flush()        #Immediately displays the character
    time.sleep(0.5)

--> Project - Password strength checker 

while True:
    password = input("Enter your password: ")

    length = len(password) >= 8
    upper = any(char.isupper() for char in password)
    lower = any(char.islower() for char in password)
    digit = any(char.isdigit() for char in password)
    special = any(char in "!@#$%^&*()-_+=[]{}\\|;:'\",.<>/?`~" for char in password)

    if length and upper and lower and digit and special:
        print("Strong Password")
        break

    elif length and (upper or lower) and (digit or special):
        print("Moderate Password")

    else:
        print("Weak Password")
